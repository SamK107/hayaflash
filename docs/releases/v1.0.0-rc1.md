## Procédure support — mot de passe oublié (V1)

**Décision du 29/09** : pas de récupération en libre-service en V1. Procédure
manuelle, par l'équipe HayaFlash :

1. **Demande** : le vendeur écrit au support **depuis le numéro inscrit sur son
   compte** (WhatsApp). Une demande venant d'un autre numéro est refusée.
2. **Vérification d'identité** par l'admin : le numéro de l'expéditeur
   correspond exactement au `phone` du compte ; au moins un élément que seul le
   titulaire connaît est confirmé (nom de la boutique, date ou titre d'une
   vente récente, dernier plan payé).
3. **Mot de passe temporaire** : défini dans l'admin Django (`/admin/` →
   utilisateur → « Modifier le mot de passe »), aléatoire, jamais réutilisé.
   Action tracée : une ligne dans le journal d'audit (qui, quand, quel compte,
   motif « réinitialisation support »). Si l'admin Django ne produit pas cette
   trace automatiquement, c'est un finding à ouvrir (à vérifier par l'audit).
4. **Transmission** par WhatsApp, **au numéro inscrit uniquement**, avec la
   consigne de changer le mot de passe dès la connexion (`/seller/parametres/`).
5. Aucune information sur le compte n'est donnée tant que l'étape 2 n'est pas
   validée.

**V2** : réinitialisation par OTP SMS, quand un vrai fournisseur SMS sera
branché (préalable : correction du code OTP dormant, F-05).
