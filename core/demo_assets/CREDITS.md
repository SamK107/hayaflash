# Crédits des images de démo

Aucune image tierce n'est versionnée : le seed de démo (`seed_marche_demo`) génère ses images avec Pillow.

Si des photos sont ajoutées un jour à `core/demo_assets/produits/` (avec `catalogue.csv`), lister ici pour chacune : fichier, auteur, licence et lien vers la source, même pour le domaine public. Seules les images dont la licence a été vérifiée (domaine public ou CC0) doivent entrer dans le dépôt.
